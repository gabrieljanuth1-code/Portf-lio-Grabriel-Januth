# Portf-lio-Grabriel-Januth
Este é o meu portfólio pessoal, projetado para reunir e apresentar minha trajetória como Engenheiro de Computação. A proposta do projeto foi criar uma interface moderna, no estilo dark mode, inspirada no ecossistema de desenvolvimento, entregando uma navegação fluida, direta e focada no que importa: código, dados e soluções reais.

A estrutura do site cobre os principais pilares da minha atuação profissional:

Início e Sobre Mim: Apresento meu perfil como estudante da Universidade CEUMA em São Luís (MA), destacando a união entre a base de hardware e a prática no desenvolvimento de software focado em resolver problemas reais.

Stack Técnico: Mapeamento transparente das ferramentas que domino, com foco em Python, ecossistema de dados (Pandas, NumPy, Matplotlib), sistemas embarcados e práticas avançadas de versionamento com Git e GitHub.

Projetos: Exibição de cases práticos, como o Sistema de Curva de Carga voltado para análise de consumo elétrico empresarial, além da aplicação contínua de boas práticas de desenvolvimento.

Contato: Uma área interativa estilizada com sintaxe de código em Python, conectando diretamente meus canais para redes sociais, e-mail e novas oportunidades.
